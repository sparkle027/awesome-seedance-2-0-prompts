## 🎬 什么是 Seedance 2.0？

Seedance 2.0 是一款最先进的 AI 视频生成模型。只需输入文本提示词（文生视频）或起始图像（图生视频），它就能制作出具有连贯物理效果、摄像机运镜和角色的短片，且动作幅度大，极具电影感。

本列表收集了在 X 上真正走红的提示词——这样你就能看到杰出片段背后的确切措辞，然后将其重新混合，创作属于你自己的作品。

- 🎥 **通过单一提示词进行文生视频和图生视频**
- 🎬 电影级的摄像机运镜和连贯的主体
- ⚡ 快速迭代——调整一行代码，重新生成
- 🔌 可通过 gptproto Seedance 2.0 API 使用
