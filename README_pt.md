## 🎬 O que é Seedance 2.0?

Seedance 2.0 é um modelo de geração de vídeo por IA de última geração. Dê a ele um prompt de texto (texto para vídeo) ou uma imagem inicial (imagem para vídeo) e ele produz clipes curtos, cinematográficos e de alto movimento com física, movimentos de câmera e personagens coerentes.

Esta lista coleta prompts que viralizaram no X — para que você possa ver a redação exata por trás de clipes de destaque, e então remixá-los para os seus.

- 🎥 **Texto para vídeo e imagem para vídeo a partir de um único prompt**
- 🎬 Movimento de câmera cinematográfico e personagens consistentes
- ⚡ Iteração rápida — ajuste uma linha, regenere
- 🔌 Disponível através da API Seedance 2.0 do gptproto
