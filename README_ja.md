## 🎬 Seedance 2.0 とは？

Seedance 2.0 は最先端のAI動画生成モデルです。テキストプロンプト（テキストから動画）や開始画像（画像から動画）を与えることで、物理法則、カメラワーク、キャラクターの一貫性が保たれた、短くダイナミックで映画のようなクリップを生成します。

このリストは、Xで実際に拡散されたプロンプトを収集しています。優れたクリップの背後にある正確な表現を確認し、それを元に自身の作品をリミックスすることができます。

- 🎥 **1つのプロンプトからテキストから動画・画像から動画を生成**
- 🎬 映画のようなカメラワークと一貫性のある被写体
- ⚡ 高速な反復 — 1行調整して再生成
- 🔌 gptproto Seedance 2.0 APIを通じて利用可能
