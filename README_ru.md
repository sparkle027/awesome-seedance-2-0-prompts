## 🎬 Что такое Seedance 2.0?

Seedance 2.0 — это передовая модель генерации видео с помощью ИИ. Дайте ей текстовый промпт (text-to-video) или исходное изображение (image-to-video), и она создаст короткие, динамичные кинематографичные клипы с согласованной физикой, движениями камеры и персонажами.

В этом списке собраны промпты, которые стали виральными на X, поэтому вы можете увидеть точные формулировки, стоящие за крутыми клипами, и использовать их для создания своих собственных.

- 🎥 **Text-to-video и image-to-video по одному промпту**
- 🎬 Кинематографичное движение камеры и согласованность объектов
- ⚡ Быстрая итерация — измените строчку, сгенерируйте заново
- 🔌 Доступно через gptproto Seedance 2.0 API
