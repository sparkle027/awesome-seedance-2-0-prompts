## 🎬 Was ist Seedance 2.0?

Seedance 2.0 ist ein hochmodernes KI-Videogenerierungsmodell. Gib ihm einen Text-Prompt (Text-zu-Video) oder ein Startbild (Bild-zu-Video) und es erstellt kurze, dynamische, filmische Clips mit konsistenter Physik, Kamerabewegungen und Charakteren.

Diese Liste sammelt Prompts, die auf X viral gegangen sind — so kannst du den genauen Wortlaut hinter herausragenden Clips sehen und sie dann für deine eigenen remixen.

- 🎥 **Text-zu-Video & Bild-zu-Video aus einem einzigen Prompt**
- 🎬 Filmische Kamerabewegungen und konsistente Motive
- ⚡ Schnelle Iteration — eine Zeile anpassen, neu generieren
- 🔌 Verfügbar über die gptproto Seedance 2.0 API
